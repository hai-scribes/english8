# Tiếng Anh 8 — Global Success: Syllabus Map

Reference spec for building our own lesson materials aligned to the national
grade-8 English textbook (NXB Giáo dục Việt Nam × Pearson, 2018 curriculum;
chief editor GS.TS. Hoàng Văn Vân).

This file records **what each unit teaches** — themes, target phonology, and
grammar. It is a curriculum map compiled from public sources, not textbook
content. All teaching material we write against it is original.

## Unit structure

Every unit follows the same seven-lesson shape:

| Lesson | Purpose |
| --- | --- |
| Getting Started | Opening dialogue; introduces topic + core lexis in context |
| A Closer Look 1 | Vocabulary set + pronunciation target |
| A Closer Look 2 | Grammar target |
| Communication | Functional language + "Everyday English"; cultural content |
| Skills 1 | Reading → Speaking |
| Skills 2 | Listening → Writing |
| Looking Back & Project | Consolidation + extended task |

Review units fall after Units 3, 6, 9, and 12.

### Writing genre summary

Eight of twelve units land on some form of paragraph, and eleven of twelve run to
80–100 words — Unit 7's notice is the sole exception on both counts. The genre
distribution:

- **Paragraph** — U2, U3, U4, U6, U8 (opinion/description)
- **Descriptive paragraph** — U10, U12
- **Persuasive paragraph** — U11
- **Email** — U1 (informal), U5 (advice)
- **Notice** — U7 (the one formal/public genre; also the longest at ~100–120w)

The recurring rhetorical move is **balanced argument then position**: U6, U8,
and U11 all ask for advantages/disadvantages or a for/against stance. Worth
teaching that structure once, early, and reusing it.

## Notes on progression

- **Phonology** runs vowel contrasts (U1–U4) → nasal and consonant clusters
  (U5–U8) → suprasegmentals: word stress, sentence stress, intonation (U9–U12).
  Later units need audio, not just print.
- **Grammar** builds sentence complexity: simple → compound (U3) → complex with
  subordination (U7) → reported speech (U11–U12). Units 11 and 12 are the
  heaviest and deserve the most practice material.
- **Themes** alternate between personal/local (leisure, countryside, teenagers,
  shopping) and civic/global (ethnic groups, environment, disasters, science).
