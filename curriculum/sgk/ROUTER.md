# Where to look in the recorded book

The record is ~4,400 lines across seventeen files. **Do not read it wholesale
to answer one question.** Grep `index.jsonl`, open the one section it names.

```sh
grep -i 'past continuous' curriculum/sgk/index.jsonl   # by natural term
grep '"everyday-english"' curriculum/sgk/index.jsonl   # by controlled tag
grep '"unit": 7,' curriculum/sgk/index.jsonl           # everything in one unit
```

Every row carries the `file` to open, the `sec` heading to find in it, and a
`line` number where the section is an actual heading. Rows are also emitted for
things that are *not* headings — the named grammar targets, the pronunciation
pair, the Everyday English function, the content block, the unit's whole lexis —
because the book's own headings say "A Closer Look 2" and nothing more, and no
amount of grepping headings will tell you which unit teaches the passive.

`index.jsonl` is generated by `tools/index_sgk.py` from the record itself.
Never hand-edit it; regenerate it in the same change that edits the record, and
`python3 tools/index_sgk.py --check` will tell you if it has fallen behind.

## The controlled tags

| Tag | What it marks |
| --- | --- |
| `unit` · `section` | a heading inside one of `unit-NN.md` |
| `target` | a named teaching target, not a heading — grammar, pronunciation, function, content block, lexis |
| `getting-started` · `closer-look-1` · `closer-look-2` · `communication` · `skills-1` · `skills-2` · `looking-back` | the book's seven sections |
| `vocabulary` · `pronunciation` · `grammar` | what a Closer Look teaches |
| `everyday-english` · `content-block` | the two halves of Communication |
| `reading` · `speaking` · `listening` · `writing` | the four skills |
| `project` · `now-i-can` | how a unit ends |
| `lexis` · `glossary` · `ipa` | the words, and the book's own IPA and Vietnamese |
| `review` · `cumulative` | Reviews 1–4 |
| `book-map` · `overview` | the Book Map, pp. 4–7 |

## Common questions, and where they are answered

| Question | Where |
| --- | --- |
| Which unit teaches *X* grammar? | `grep -i 'X' index.jsonl`, tag `grammar` |
| What sounds does unit N teach? | `grep '"unit": N,' index.jsonl \| grep pronunciation` |
| What speech act is unit N's Everyday English? | tag `everyday-english` — the book names a different one each unit |
| What is unit N's Communication content block? | tag `content-block` — the half our units historically dropped |
| Is word *W* in the book at all, and where? | `grep -i '"W"' index.jsonl` — the `lexis` row names the unit |
| What is *W*'s IPA and Vietnamese? | the `glossary` row for that unit → `glossary.md` |
| What does a unit's shape look like? | `book-map.md` §"The shape every unit takes" |
| What is in Review N? | tag `review` → `reviews.md` |
| Are we behind the book on unit N? | not here — run `python3 tools/check_coverage.py --unit N` |

## What this is not

The record holds **syllabus facts**: what each exercise asks, what type it is,
what language it targets. Reading passages, listening scripts and dialogues are
described, not reproduced — topic, length, structure, the facts the questions
turn on. See `README.md` for why, and for the copyright line that draws it.

So the index will tell you that Unit 3's Skills 2 listening is a conversation
about teen stress on tracks 17–18, and what the questions turn on. It will not
give you the script, because the record does not hold one.

## The book itself

`PROVENANCE.md` records where the source PDF is, what its checksum is, and how
its page numbers map onto the book's. The PDF is **not** in this repo and should
